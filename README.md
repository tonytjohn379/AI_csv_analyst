AI-Powered CSV Data Analyst

An AI-powered data analysis web application built with Python, Streamlit, Pandas, Plotly, SQLite, and Google Gemini. The application allows users to upload CSV datasets, explore data quality, ask questions in natural language, generate SQL queries using AI, and visualize analysis results.

Features
CSV Upload: Upload CSV files and analyze datasets interactively.
Data Preview: View dataset rows, column names, and data types.
Data Profiling: Identify missing values, duplicate records, and basic dataset statistics.
AI-Powered SQL Generation: Convert natural-language questions into SQLite queries using Google Gemini.
SQL Execution: Execute generated read queries against the uploaded dataset.
Data Visualization: Create interactive charts using Plotly.
AI-Generated Insights: Get explanations and summaries of query results.
Export Results: Download analyzed data as a CSV file.
Interactive Interface: Explore datasets through a user-friendly Streamlit application.
